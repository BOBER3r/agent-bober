# ADR-1: Graph runtime — native TypeScript superstep interpreter

**Decision:** Implement the executable graph semantics (superstep scheduling, dynamic routing, fan-out/fan-in, bounded loops, durable resume) as a native TypeScript Pregel loop in `src/pge/runtime/**`, adopting LangGraph's semantics by name while taking neither `langgraph` (Python) nor `@langchain/langgraph` (JS) as a dependency.

**Context:** The PGE goals require executable graph semantics (G3) on top of an owned, versionable topology artifact (G1/G2/G4). LangGraph supplies G3 and the inspection half of G1, but its serialization describes an already-compiled graph, expands conditional edges to every declared target, and never serialises router bodies (https://langchain-ai.github.io/langgraphjs/reference/classes/langgraph.Command.html; https://docs.langchain.com/oss/javascript/langgraph/graph-api) — so the spec/compiler layer must be written regardless of which runtime executes it. The only remaining question is whether to also own the runtime.

**Options Considered:**

| Option | Pros | Cons |
|--------|------|------|
| **A. LangGraph Python (`langgraph` 1.2.10)** | Largest ecosystem (38,955 stars); most worked examples; every needed primitive present | Requires a second language runtime, a 40–70 MB PyInstaller bundle across six platform targets, and a Zod→JSON Schema→Pydantic codegen chain with a hand-maintained refinement-parity file; contract validation happens twice in two languages |
| **B. LangGraph.js (`@langchain/langgraph` 1.4.9)** | Same language; Send/Command/`Command.PARENT`/interrupt/`defer` all present; Zod is the native state-schema language via Standard Schema; official `@langchain/langgraph-checkpoint-validation` 1.1.0 certifies a custom saver | Adds 11.4 MB to the execution path (`@langchain/langgraph` 4.14 MB + mandatory `@langchain/core` 7.29 MB pulling `langsmith`, `js-tiktoken`, `mustache`); forces `engines.node` `>=18`→`>=20` and `zod` `^3.24.2`→`^3.25.32`, both semver-visible to consumers; installs an import-time `initializeAsyncLocalStorageSingleton()` global; open defect langgraphjs#2656 silently drops every Send fan-out task at `maxConcurrency: 1` |
| **C. Native TypeScript superstep interpreter** | Zero vendor coupling in the execution core; interrupts can fire between supersteps instead of mid-node; reducers can be order-invariant rather than merely associative; gives first production callers to `Scheduler`/`Semaphore` (`scheduler.ts:54-165`), `Budget` (`budget.ts:40`), `retry.ts:61-131` and `reconciler.ts:17`, all green but with zero or near-zero live callers | ~1,400 non-test lines of new runtime across eight modules, owned permanently; barrier, crash-resume and commit-atomicity bugs are silent and state-corrupting, with no upstream maintainer and no vendor conformance suite |

**Rationale:** The Problem Statement's **Distribution** constraint states "no second language runtime, no per-platform binary" for a CLI symlinked into arbitrary user projects — Option A is eliminated outright, and the supplied LangGraph research independently concludes "do not pursue Python interop". Between B and C, the **No SDK lock-in in the execution path** locked dependency and the **success criterion "the same golden spec at concurrency 1 and concurrency 8 produces byte-identical `.bober/` artifacts"** decide it: Option B cannot ship the mandated default concurrency of 1 at all, because langgraphjs#2656 (open, filed against 1.4.8) executes 0 of 6 fan-out tasks with no error and structurally valid output, forcing a permanent `Math.max(2, requested)` floor plus re-bounding with this repo's own `Semaphore` — paying for a scheduler and then writing one anyway. Option B is eliminated.

**Consequences:** `src/pge/runtime/**` owns `GraphInterpreter`, `FrontierPlanner`, `CommitBoundary`, `FsCheckpointer`, `InterruptController`, `ReducerRegistry`, `RetryPlanner` and the state-size guard. `package.json` gains no runtime dependency and no `engines`/`zod` range change. `Scheduler` gains one method (`settle`, ~25 lines) — the only edit to a shipped runtime file. Interrupts fire at superstep boundaries (ADR-6) and reducers take batches (ADR-4), neither of which LangGraph can express.

**Risk:** If the barrier, resume or commit semantics carry a defect, run state corrupts silently and the failure is attributed to the LLM rather than the runtime. Three blocking invariant suites (determinism, exactly-once via a write-counter spy, kill-and-resume in a fresh process) plus a checkpointer suite modelled on the published `@langchain/langgraph-checkpoint-validation` contract with kill-mid-write fault injection are the only defence; if they are treated as optional, this decision becomes indefensible.
